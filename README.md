## 📖 О проекте

**Brick Box V1** — компактный контроллер на базе микроконтроллера **ESP32-S3**, созданный для плавного, тихого и гибкого управления самодельными радиоуправляемыми моделями и техникой LEGO Technic.

### ✨ Ключевые возможности
* **🚀 Плавный старт (0,35 с):** ходовые моторы разгоняются мягко, без рывков и пробуксовки шестерён.
* **🚙 Режим полного привода ALT (4×4):** мгновенное объединение моторов `M1–M4` в единую синхронную тягу одним нажатием.
* **🎮 Двойное управление «из коробки»:** автоматический поиск геймпада **Xbox** по Bluetooth при включении (25 сек) или автоматический запуск **Wi-Fi веб-пульта** для смартфона без установки приложений.
* **🔊 Встроенный клаксон («Бип-бип»):** генератор двухполярного сигнала использует обмотку мотора `M3` как динамик — модель умеет сигналить без установки отдельной пищалки.
* **💾 Энергонезависимая память (NVS):** все настройки инверсии каналов и режимов привода сохраняются автоматически и не сбрасываются при отключении питания.
* **🛡️ Защита Fail-Safe:** мгновенная остановка всех моторов и снятие питания при потере связи или закрытии пульта.

## 🔋 Питание и бережная эксплуатация

* **Поддерживаемое питание:** аккумуляторы **2S (7.4 В)** и **3S (11.1 В)** LiPo / Li-Ion.

> ⚠️ **Рекомендации по безопасности:**
> * Используйте аккумуляторы с токоотдачей, соответствующей нагрузке ваших моторов.
> * Не допускайте глубокого разряда батареи.
> * Если модель упёрлась в препятствие или колёса заблокированы — **не продолжайте удерживать газ**, чтобы избежать перегрева моторов и силовых драйверов.

## 📡 Подключение и управление

### Вариант А: Геймпад Xbox (Bluetooth LE)
1. Включите питание **Brick Box V1** — светодиод начнёт мигать зелёным.
2. В течение **25 секунд** включите геймпад Xbox (при первом подключении переведите его в режим сопряжения).
3. После успешного соединения светодиод загорится ровным цветом.

### Вариант Б: Смартфон (Wi-Fi веб-пульт)
1. Если геймпад не подключён за 25 секунд, контроллер автоматически создаст точку доступа Wi-Fi.
2. Подключитесь к сети **`Brick Box V1`** (пароль: **`legolego`**).
3. Откройте в браузере адрес **`http://192.168.4.1`** (если телефон предупредит об отсутствии интернета — выберите *«Не отключаться»*).
4. *Совет:* нажмите кнопку **`⛶`** в интерфейсе пульта или добавьте страницу на главный экран смартфона, чтобы управлять моделью на весь экран без адресной строки.

## 🎮 Горячие клавиши и комбинации (Геймпад Xbox)

| Кнопка / Комбинация | Действие |
| :--- | :--- |
| **RT / LT (Курки)** | Плавный газ вперёд / назад (`M1`, `M2`; в режиме 4×4 — `M1–M4`) |
| **Левый / Правый стик** | Рулевое управление (`GeekServo 1/2`) и спецканал `M5` |
| **Крестовина ↑/↓** и **Y / A** | Управление доп. каналами `M3` и `M4` в обычном режиме |
| **Меню (`≡`)** или **Share** | Звуковой сигнал клаксона «Бип-бип» (через мотор `M3`) |
| **Удерж. View (`⧉`) 2 сек** | Переключение режима привода: **Обычный ↔ ALT (4×4)** |
| **Удерж. L3 + R3 (0,7 сек)** | Поменять левый и правый стики местами |
| **LB + Y** / **RB + A** | Инверсия мотора `M1` / инверсия мотора `M2` |
| **LB + L3** / **RB + R3** | Инверсия мотора `M3` / инверсия мотора `M4` |
| **LB + RB** | Инверсия спецканала `M5` |
| **LB + X** / **RB + B** | Инверсия `GeekServo 1` / инверсия `GeekServo 2` |

## 💡 Световая индикация (RGB LED)

| Цвет / Режим | Значение статуса |
| :--- | :--- |
| 🟢 **Мигает зелёным** | Поиск геймпада Xbox (первые 25 секунд после включения) |
| 🔵 **Горит синим** | Подключено, активен стандартный режим привода |
| 🟣 **Мигает / горит фиолетовым** | Режим Wi-Fi пульта или активен полный привод **ALT (4×4)** |
| 🔴 **Горит красным** | Включена инверсия одного из ходовых моторов (`M1` или `M2`) |
| 🟡 **Вспышка жёлтым / белым** | Сработал клаксон или подтверждено сохранение настройки |
